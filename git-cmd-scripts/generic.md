# Not all possible options

> The library should:
- have all "standard CLI options" at a set version
- Also Implement those same actions via libgit2
- Have a config setting to use
   - CLI
   - library, or
   - whichever is available

• git init: Initializes a new, empty Git repository.
• git clone: Copies a remote repository onto your local machine.
• git add: Stages changes for your next commit.
• git commit: Records staged changes as a snapshot in history.
• git status: Shows the current state of your working tree and staging area.
• git log: Displays commit history.
• git diff: Shows changes between commits, commit and working tree, etc..
• git checkout / git switch: Switches branches or restores working tree files.
• git branch: Lists, creates, or deletes branches.
• git merge: Joins two or more development histories together.
• git rebase: Reapplies commits on top of another base tip.
• git pull / git push: Fetches/integrates or pushes remote repository changes.
• git submodule: Manages embedded repositories within a parent project.
